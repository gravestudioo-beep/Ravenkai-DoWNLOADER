# 🌙 Ravenkai DOWNLOADER Ultra v3 — 1000-upgrade branch

Большой апдейт исходного Ravenkai. В этой ветке переработаны ядро очереди, база, UI, история, настройки, Premium-ограничения, админка, прогресс, обработка ошибок и интеграция визуальных ассетов.

## Что добавлено

- Реальная worker-очередь с несколькими воркерами и отменой задач.
- Предпросмотр метаданных до скачивания: название, автор, длительность, примерный размер.
- Качества 360/480/720/1080, а для Premium — 1440/4K.
- MP4/WEBM и MP3/M4A.
- История с пагинацией, удалением записей и полной очисткой.
- Профиль со статистикой пользователя.
- Настройки качества, формата, автоудаления и уведомлений.
- Premium UI + отдельный лимит размера.
- Админ-команды `/admin`, `/stats`, `/users`, `/logs`, `/ban`, `/unban`, `/broadcast`.
- База SQLite в WAL-режиме и журнал действий.
- Красивая карточка старта и отдельный блок автора.
- Новые изображения девушки/парня и dark-fantasy assets.
- Docker + FFmpeg + постоянные volumes.
- Защита от слишком частых запросов и проверка URL.
- Очистка временных файлов после каждой задачи.
- Перед отправкой файла проверяется реальный размер.

## Запуск

1. Скопируй `.env.example` в `.env`.
2. Вставь новый `BOT_TOKEN`.
3. Укажи `ADMIN_IDS`.
4. Установи FFmpeg локально или используй Docker.
5. `pip install -r requirements.txt`
6. `python -m bot.main`

## Docker

`docker compose up -d --build`

## Важно

Используй бот только для материалов, которые тебе разрешено скачивать. Проект не реализует обход DRM/логинов/геоблокировок и не удаляет водяные знаки.
